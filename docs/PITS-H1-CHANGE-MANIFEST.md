### Database contract

- Tenant-safe composite FKs and deferred aggregate checks protect exact CORPORATE_SKU, explicit IEPS/tax baseline, at least one business
  type, and an active same-currency ORGANIZATION SALE_PRICE/PURCHASE_COST pair. Statement transition-table triggers bump ordered parent rows
  so READ COMMITTED and REPEATABLE READ races cannot commit write skew; the 250-item bulk case records time/plan without a hardware-specific
  threshold.
- Override lifecycle, maker-checker, one-current REQUESTED/APPROVED uniqueness and immutable supersession are durable. Publication lines
  carry exact field decisions and binding target provenance. APPLIED has a non-empty exact fieldMask; a REVERSION stores both
  supersedes/reverses APPLIED targets and occupies both partial-unique slots. Lineage reachability uses deduplicated `UNION` across both
  edges to reject cycles without exponential path enumeration.
- Import/binding/publication/idempotency/outbox state shapes reject whitespace-only actor/lease/failure fields, residual leases, impossible
  terminal combinations and malformed hashes. Preview tokens are stored only as SHA-256 hashes.
- Every populated `ActivityLog.organizationId` is immutable and `ON DELETE RESTRICT`. HUMAN uses equal legacy `staffId` and durable
  `actorStaffId`; SERVICE uses only a nonblank service principal; legacy rows may keep null classification and historical
  `staffId SET NULL`. Task 10 owns the application deactivate/revoke/anonymize flow before any H1 endpoint is exposed.
- Product/binding/publication history uses deferred `NO ACTION` where an individual delete must preserve provenance, while complete Venue
  deletion purges the venue graph. Direct tests include binding lines, rollout, requirements, observations, readiness, overrides,
  publication decisions and outbox rows.

### Recovery and rollout

- CIC failure: inspect exact `indisvalid/indisready`; if invalid, standalone `DROP INDEX CONCURRENTLY`, then
  `prisma migrate resolve --rolled-back <exact_cic_phase>` and retry. If exact index is valid/ready, resolve applied. Never use
  `IF NOT EXISTS` or mark an invalid index applied.
- Bounded FK/check/trigger `55P03`: prove the transaction rolled back and left no partial object set, resolve only that exact phase rolled
  back, then retry in a deployment window. Do not run the CIC drop procedure for transactional DDL.
- Production rollback is gate-based/default-off; do not drop catalog/audit history. No production or remote database was contacted and no
  Git mutation was performed.
