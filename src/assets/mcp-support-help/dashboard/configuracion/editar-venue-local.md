## Antes de empezar

Editar el venue cambia datos del local, no de tu usuario. Esta sección puede incluir información básica, contacto, imágenes, documentos fiscales y opciones generales; las integraciones están aparte, en **Configuración > Integraciones**. Antes de guardar, confirma que estás en la sucursal correcta y que el cambio corresponde a ese local.

Algunos campos afectan canales públicos o procesos operativos. Por ejemplo, imágenes pueden mostrarse al cliente, documentos pueden afectar KYC o pagos, e integraciones pueden cambiar sincronizaciones externas.

## Pasos

1. Abre **Configuración** y, en **Este local**, entra a **Información del local**.
2. Entra a **Información Básica** para revisar nombre, dirección y datos generales.
3. Usa **Contacto e Imágenes** para actualizar teléfono, correo, identidad visual o medios visibles.
4. Usa **Documentación** para cargar archivos fiscales, KYC o documentos requeridos.
5. Abre **Configuración > Integraciones** para revisar conexiones como **Google Business Profile** u otros servicios.
6. Guarda cada cambio y valida en la vista donde impacta: cliente, pagos, reservaciones o reportes.

## Problemas frecuentes

Si no puedes editar, tu usuario no tiene rol administrativo. Si una imagen no cambia, revisa formato, peso y caché del navegador. Si un documento queda pendiente, espera revisión o revisa si falta algún archivo requerido. Si una integración falla, confirma que la cuenta externa sea la correcta y que tenga permisos suficientes.

## Validaciones después de editar

Para datos públicos, revisa la experiencia del cliente o canal donde se muestre el local. Para documentos, confirma estado de revisión y que no haya rechazos. Para integraciones, realiza una prueba concreta, como sincronizar una reserva, abrir un enlace o validar que la cuenta conectada sea la esperada.

Si el cambio afecta pagos, no lo pruebes con un cliente real primero. Usa un caso controlado o pide apoyo a soporte para validar configuración.

## Cuándo pedir ayuda

Escala si un documento aprobado aparece rechazado, si el local muestra datos de otra sucursal, si una integración queda conectada a una cuenta equivocada o si no puedes guardar información crítica. Incluye sucursal, campo afectado, fecha del cambio y captura antes/después.
