## Antes de empezar

Ten a la mano el correo con el que te dieron acceso al Dashboard. El acceso depende de que tu usuario esté activo y asignado al local correcto. Si trabajas con varias sucursales, el mismo usuario puede ver más de una, pero cada una puede tener permisos distintos.

También confirma que estás entrando al Dashboard Web, no a una herramienta interna o a una liga de pago pública. La pantalla correcta debe pedir correo y contraseña de usuario.

## Pasos

1. Abre la URL oficial del Dashboard.
2. Escribe tu correo completo, sin espacios al inicio o al final.
3. Escribe tu contraseña.
4. Si el navegador ofrece guardar la contraseña, confirma que sea para el dominio correcto.
5. Al entrar, revisa el nombre del local activo en el selector de sucursales.
6. Si esperabas otra sucursal, cambia de local antes de revisar pagos, pedidos o reportes.

## Problemas frecuentes

Si la contraseña no funciona, usa recuperación de contraseña antes de pedir un nuevo usuario. Si entras pero no ves una sección, el problema normalmente es de permisos, no de inicio de sesión. Si no aparece ninguna sucursal, pide a un OWNER o ADMIN que revise que tu usuario esté asignado al local y que siga activo.

## Validaciones de acceso

Después de entrar, confirma tres cosas: correo de usuario, sucursal activa y secciones visibles en el menú. Si el usuario trabaja en varias sucursales, cambia de local y revisa si el menú se actualiza. Esto ayuda a separar problemas de sesión de problemas de permisos.

Si vas a compartir instrucciones con un nuevo miembro del equipo, dile que use siempre el dominio oficial del Dashboard y que no comparta contraseñas. Para roles operativos, conviene probar el acceso antes del turno para evitar bloqueos durante servicio.

## Cuándo pedir ayuda

Pide soporte si el usuario no recibe recuperación de contraseña, si el login entra en ciclo, si aparece una pantalla sin sucursales después de confirmar asignación o si Google Sign-In falla en el dominio correcto. Incluye correo del usuario y sucursal esperada.
