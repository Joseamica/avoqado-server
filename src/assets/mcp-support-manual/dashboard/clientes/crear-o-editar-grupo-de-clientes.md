## Antes de empezar

*Grupos de Clientes* sale en *Clientes* si tienes permiso para ver clientes y grupos. Para crear un grupo necesitas permiso para crear grupos; para cambiarlo, o para meterle o sacarle clientes, permiso para editar grupos.

## Pasos

1. En *Clientes* › *Grupos de Clientes*, toca *Nuevo Grupo de Clientes*.
2. Escribe el *Nombre del Grupo* y, si quieres, la *Descripción*. El *Color* ya trae uno: cámbialo si quieres.
3. Si quieres, en *Clientes* toca *Seleccionar clientes...* y elige quiénes entran.
4. Toca *Crear Grupo*: sale «Grupo de clientes creado exitosamente».
5. Para cambiar uno, en la lista toca ⋯ › *Editar*, haz el cambio y toca *Guardar Cambios*.

## Problemas frecuentes

- Si sale «El nombre del grupo es requerido», escribe el nombre.
- Si al crear sale «Error», aunque diga que ya existe un grupo con ese nombre, no lo vuelvas a crear: pudo quedar creado en un primer intento (y, si elegiste clientes, sin ellos). Pide que lo revise una persona del equipo de Avoqado.
